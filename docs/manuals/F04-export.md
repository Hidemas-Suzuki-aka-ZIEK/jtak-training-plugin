# JTAK 取扱説明 — テキスト・PDF の書き出し（F04）

> **TRAINING USE ONLY / 訓練用**
>
> JTAK はミルシム・タクティカルトレーニングで JTAC の役を練習するためのプラグイン。
> 実際の作戦・実弾の射撃・実在の航空機の統制には使わない。画面には、いつも「TRAINING USE ONLY / 訓練用」が出る。この表示を消す設定はない。
>
> **書き出したファイルにも、いつもこの表示が入る。** テキストは最初の行と最後の行、PDF はどのページにも上と下に入る。表示を外して書き出す設定はない。

- 日付: 2026-11-09
- 対象: ATAK-CIV 5.8.0.9 に読み込んだ JTAK

画面の名前（ボタン・欄）は、プラグインの画面に出る文字のまま「」で書く。

## 1. この機能でできること

- 「9-line」「Routing」「Check-in」「Game plan」の画面で作った書式を、テキストのファイル（`.txt`）か PDF のファイル（`.pdf`）にして端末に保存する。
- 保存したあと、Android の共有の画面が開く。使う人が送り先（ファイルのアプリ・メールなど）を選んで渡せる。
- 書き出せる書式は次の 4 つ。

| 画面 | 書き出す書式 |
|---|---|
| 「9-line」 | CAS Brief（9-line・Remarks・Restrictions をまとめたもの） |
| 「Routing」 | ルーティング |
| 「Check-in」 | チェックイン |
| 「Game plan」 | ゲームプラン |

「RED」の画面には書き出しのボタンがない。RED の円と表は書き出さない。

## 2. ボタンの場所と、押せるとき

- 4 つの画面のどれでも、結果の欄のすぐ下に「テキストを書き出す」と「PDF を書き出す」が横に並んでいる。
- ボタンは、その画面で書式を作れたあとだけ押せる。
  - 画面を開いたばかりで、まだ「作る」を押していないときは押せない。
  - 書式を作れず結果の欄が空になったときも押せない（例: 「9-line」の画面で Restrictions の欄が食い違って、結果が消えたとき）。
- 書き出すのは、**最後に作れた結果**である。入力を直したあと「作る」を押さずに書き出すと、直す前の結果が書き出される。直した内容を書き出したいときは、先に「作る」を押す。
- 書き出す中身は、結果の欄に出ている文と同じ。書き出しのために項目が増えたり減ったりはしない。

## 3. 書き出す

1. 書き出したい画面で、欄を入れて「作る」を押す。結果の欄に書式が出る。
2. 「テキストを書き出す」か「PDF を書き出す」を押す。
3. ファイルが保存され、画面の下に「書き出しました: <保存先>」と出る。保存先は端末の中のフルパスで出る（例: `/storage/emulated/0/atak/export/jtak/jtak-cas-brief-20261109-153012.pdf`）。
4. 続けて、共有の画面（題は「書き出したファイルを共有」）が開く。6 章のとおり、送り先を選ぶか、閉じる。

共有の画面を閉じても、ファイルは保存先に残る。

## 4. ファイルの名前と保存先

### 4.1 保存先

- ATAK の作業のフォルダの中の `atak/export/jtak/` に保存する（例: `/storage/emulated/0/atak/export/jtak/`）。
- フォルダがなければ、初めて書き出したときに JTAK が作る。

### 4.2 名前

`jtak-<書式>-<年月日>-<時分秒>.<txt か pdf>` の形になる。

| 書式 | 名前の `<書式>` の部分 |
|---|---|
| CAS Brief | `cas-brief` |
| ルーティング | `routing` |
| チェックイン | `check-in` |
| ゲームプラン | `game-plan` |

- 例: `jtak-cas-brief-20261109-153012.txt`（2026 年 11 月 9 日 15 時 30 分 12 秒に書き出した CAS Brief のテキスト）。
- 日時は、端末に設定されている時刻（その土地の時刻）で付く。
- 名前が同じファイルがあると上書きする。名前には秒まで入るので、ふつうは重ならない。同じ書式を 1 秒のうちに 2 回書き出したときだけ、前のファイルが上書きされる。

## 5. ファイルの中身

### 5.1 テキスト（`.txt`）

- 文字コードは UTF-8（BOM なし）、改行は LF。パソコンのメモ帳などでも読める。
- **最初の行と最後の行は、どちらも `TRAINING USE ONLY / 訓練用`**。この行は 1 回ずつだけ入る。
- その間に、結果の欄と同じ順で書式の行が並ぶ。

例（チェックインの一部。値は架空のもの）:

```
TRAINING USE ONLY / 訓練用
CHECK-IN (JP 3-09.3 2014 Fig. V-4)
OWL 21, this is KESTREL 11
1 Mission number: （未入力）
…
TRAINING USE ONLY / 訓練用
```

### 5.2 PDF（`.pdf`）

- A4 の縦。文字は等幅の 10 ポイントで、黒。
- **どのページにも、上と下に太字で `TRAINING USE ONLY / 訓練用` が入る**。ページが 2 枚以上になっても、すべてのページに入る。
- 長い行は、ページの幅で折り返す。1 ページに入らないときは、次のページに続く。
- 日本語（「（未入力）」など）も、そのままの字で出る（実機で確かめた。9 章）。

## 6. 共有する

- 共有の画面は、書き出しのボタンを押したときだけ開く。
- 送り先は使う人が選ぶ。**JTAK が自分でほかの端末やサーバーへ送ることはない**。ATAK の地図の共有（CoT）にも流さない。
- 送らないときは、共有の画面を閉じればよい。ファイルは保存先に残る。
- 送ったファイルにも `TRAINING USE ONLY / 訓練用` が入っている（5 章）。受け取った人にも、訓練用のものだと分かる。

## 7. 書き出したテキストをあとで読み込む

F02 の画面に「ファイルから読み込む」を足す作業を進めている。できあがれば、書き出したテキストのファイルを読み込んで、入力の欄に戻せるようになる。

- 読めるファイルの形は、4 章・5.1 の書き出したテキストと同じ（`docs/interfaces/README.md` の 3 章）。PDF は読めない。
- ファイルを選ぶ画面は `atak/export/jtak/` から始まる。
- この取扱説明の日付の時点では、まだ使えない。使い方は、できあがったときに F02 の取扱説明に書く。

## 8. 困ったとき

| こんなとき | 出る文・わけ | すること |
|---|---|---|
| ボタンが押せない | まだ「作る」を押していない。または、書式を作れず結果の欄が空になった | 欄を入れて「作る」を押し、結果の欄に書式が出てから押す |
| 書き出したファイルが、直す前の中身になっている | 入力を直したあと「作る」を押していない（最後に作れた結果を書き出す） | 「作る」を押してから、もう一度書き出す |
| 「書き出せませんでした: <わけ>」と出る | フォルダを作れない、または書けない。端末の空きが足りないこともある | 端末の空きと、ATAK のファイルの権限を確かめて、もう一度押す。書きかけのファイルは残らず、共有の画面も開かない |
| 「共有できませんでした。ファイルは保存先にあります: <保存先>」と出る | PDF を共有の画面に渡せなかった。または、共有の画面を開けなかった | ファイルは保存できている。ファイルのアプリで `atak/export/jtak/` を開いて、そこから送る |
| テキストを共有したら、ファイルではなく文として送られた | テキストのファイルを共有の画面に渡せなかったので、同じ中身を文として渡した | ファイルは保存先にある。ファイルとして送りたいときは、ファイルのアプリから送る |
| 共有の画面にファイルの下見（小さな絵）が出ない | 共有の画面がファイルの中を読めない。わかっている問題（9 章） | そのまま送り先を選べば送れる |

どの場合も、ATAK は止まらない。

## 9. 実機で確かめたことと、まだのこと

2026-11-09 に実機（ATAK-CIV 5.8.0.9）で、CAS Brief をテキストと PDF に書き出して確かめた。

確かめたこと:

- ファイルは `atak/export/jtak/` に、4 章の名前で保存された。
- 共有の画面で送り先を選ぶと、ファイルが届いた（PDF が `Download/` に同じ大きさで保存された）。
- PDF の上と下の「TRAINING USE ONLY / 訓練用」と、日本語の「（未入力）」が正しい字で出ていた。
- テキストのファイルも、最初と最後に「TRAINING USE ONLY / 訓練用」の行があり、日本語は化けていなかった。

わかっている問題:

- 共有の画面が、送るファイルの下見を出せない。送ることはできる。直す作業は今後行う。

まだ実機で確かめていないこと:

- ルーティング・チェックイン・ゲームプランの書き出し（作りは CAS Brief と同じ）。
- PDF が 2 ページ以上になるときの見え方。
- 書き出しに失敗したとき（8 章の「書き出せませんでした」「共有できませんでした」）の表示。
