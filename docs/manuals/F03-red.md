# JTAK 取扱説明 — RED（危険見積距離）の表示（F03）

> **TRAINING USE ONLY / 訓練用**
>
> JTAK はミルシム・タクティカルトレーニングで JTAC の役を練習するためのプラグイン。
> 実際の作戦・実弾の射撃・実在の航空機の統制には使わない。画面・地図の円の説明には、いつも「TRAINING USE ONLY / 訓練用」が出る。この表示を消す設定はない。
>
> **表の値は訓練用サンプル値で、実際の安全距離・危害半径ではない。** RED の画面の先頭には、いつも次の文が出る。この文を隠す操作はない。
>
> `訓練用サンプル値 — 実際の安全距離・危害半径ではない / TRAINING SAMPLE VALUES — NOT REAL SAFETY DATA`

- 日付: 2026-11-09
- 対象: ATAK-CIV 5.8.0.9 に読み込んだ JTAK

画面の名前（ボタン・欄）は、プラグインの画面に出る文字のまま「」で書く。

## 1. この機能でできること

- 目標の点の周りに、表の行の距離ごとに円を描く。円は訓練の中で「この範囲に味方がいると危ない」という目安を見る練習に使う。
- 円の中にある味方の点を、画面に一覧で出す。
- 表の行は JTAK の画面の中で直せる。直した表は端末のファイルに保存される。

呼び方の「RED」は、JP 3-09.3 の用語 risk-estimate distance（危険見積距離）から取った名前である。名前は RED でも、表の値は実際の危険見積距離ではない。値は訓練用サンプル値のままである。

## 2. 画面の開き方

1. ATAK のツールバーから JTAK を開く。右側に JTAK の画面が出る。
2. 画面の上のボタンの 2 段目、「Game plan」の右にある「RED」を押す。RED の画面に切り替わる。
3. 画面のいちばん上の「TRAINING USE ONLY / 訓練用」の行は、RED の画面でも出たままになる。

「RED」を押して画面を開くたびに、JTAK は表のファイルと地図の点の一覧を読み直す。

## 3. 画面の並び

上から順に、次のものが並ぶ。

1. 訓練用サンプル値の文（太字。冒頭の囲みの文と同じ）
2. 題名「危険見積距離（RED）（訓練用）」
3. 表の状態の行（3.1）
4. 「目標の点」の選ぶ欄と、「点の一覧を更新」のボタン
5. 「兵器の行」の選ぶ欄と、選んだ行の輪の一覧（例: 「内側 100 m / 外側 300 m」）
6. 「描く」「消す」のボタン
7. 結果の欄（6 章）
8. 「表の編集」の節（7 章）

### 3.1 表の状態の行

いま使っている表がどれかを、次のどれかで出す。

| 出る文 | 意味 |
|---|---|
| 「表: 既定（ファイルなし）」 | 表のファイルがない。プラグインに入っている既定の表を使っている |
| 「表: ファイル（N 行）」 | 端末の表のファイルを読んで使っている。N は行の数 |
| 「表のファイルが正しくないので既定の表を使っています」 | 表のファイルを読めないか、中身が決まりに合わない。既定の表を使っている。下に理由が出る（9 章） |

### 3.2 既定の表

最初は、次の 3 行の表が入っている。

| 行（ラベル） | 輪 1 | 輪 2 |
|---|---|---|
| サンプル 小 | 内側 100 m | 外側 300 m |
| サンプル 中 | 内側 250 m | 外側 600 m |
| サンプル 大 | 内側 500 m | 外側 1000 m |

- この値には出典がない。意味のない切りのよい数を選んだ。実在の兵器の値でも、実際の安全距離・危害半径でもない。
- 3 行とも、メモは「訓練用サンプル値。実在の兵器の値ではない」。
- JTAK は行の名前の候補を出さない。

## 4. 円を描く

1. 「目標の点」の欄で、円の中心にする点を選ぶ。
   - 一覧には、地図の点が名前で出る。自分の点も出る。最初の値は「（選ばない）」。
   - LRF で置いた点（F01）も選べる。
   - 一覧の出方は 9-line の画面と同じ（F01・F02 の取扱説明 3.1）。JTAK が描いた円は、一覧に出ない。
   - 点を足したり動かしたりしたあとは、「点の一覧を更新」を押す。
2. 「兵器の行」の欄で、表の行を選ぶ。その下に、選んだ行の輪が「内側 100 m / 外側 300 m」の形で出る。
3. 「描く」を押す。

描かれる円:

- 選んだ点の位置を中心に、輪ごとに 1 つの円を描く。輪は 1 行に 1〜3 つある。
- 円は線だけで、中は塗らない。線の色は内側の輪から順に、赤・橙・黄。
- 円の題名は「訓練用 {ラベル} {輪の名前} {半径} m」。例: 「訓練用 サンプル 小 内側 100 m」。
- 円の説明（remarks）には、次の行が順に入る。
  1. `TRAINING USE ONLY / 訓練用`
  2. `訓練用サンプル値 — 実際の安全距離・危害半径ではない / TRAINING SAMPLE VALUES — NOT REAL SAFETY DATA`
  3. 「目標: {目標の点の名前}」
  4. 行のメモ（メモが空なら、この行は出ない）
- 円は ATAK の描画の道具と同じグループ（Drawing Objects）に入る。そのグループがないときは、「JTAK 訓練用の RED」というグループを作って入れる。
- JTAK は円の中心に点を置かない。

注意:

- 「描く」を押すたびに、円が足される。前に描いた円は消えない。描き直すときは、先に「消す」を押す。
- 目標の点があとで動いても、円は動かない。描き直す。
- 「描く」を押したとき、JTAK は地図の点の一覧を取り直す。選んだ点が地図から消えていると、円を描かずに「目標の点を選んでください」と出る。

## 5. 円を消す

- 「消す」を押すと、JTAK が描いた円をすべて地図から取り除く。結果の欄に「消した円: N」と出る。
- ATAK の操作で先に消した円は、N に数えない。
- ほかの点や、利用者が ATAK で描いた図形は消さない。
- JTAK の画面を閉じたとき（プラグインが閉じられたとき）も、JTAK が描いた円を取り除く。

## 6. RED の円の中の味方の点

「描く」を押すと、結果の欄に次の形で出る。先頭の行はいつも `TRAINING USE ONLY / 訓練用`。

円の中に味方の点があるとき:

```
TRAINING USE ONLY / 訓練用
RED の円の中の味方の点:
{点の名前} — {輪の名前}（{距離} m）
…
```

円の中に味方の点がないとき:

```
TRAINING USE ONLY / 訓練用
RED の円の中の味方の点: なし
```

決まり:

- 味方として数える点は、自分の点と、種類（CoT の type）が `a-f-` で始まる点。敵の点・不明の点は数えない。
- 目標に選んだ点そのものは数えない。
- 目標からの距離が、いちばん外側の輪の半径以下なら「中にある」とする。距離が半径とちょうど同じ点も中に入れる。
- 輪の名前には、その点が入るいちばん内側の輪の名前が出る。
- 距離は目標からの距離で、整数の m（四捨五入）。近い順に並ぶ。
- 距離を計算できなかった点は、中にあるとはみなさない。そのような点があると「距離を計算できなかった点: N」と出る。
- 一覧は「描く」を押したときの位置で作る。あとで点が動いても、一覧は変わらない。もう一度「描く」を押すと、新しい位置で作り直す（円も足される。4 章の注意）。
- 結果の欄の文字は選んでコピーできる。

## 7. 表を編集する

「表の編集」の節で、「兵器の行」の欄で選んだ行を直す。

### 7.1 欄

| 欄 | 入れるもの |
|---|---|
| 「ラベル」 | 行の名前。1〜40 文字 |
| 「輪 1 の名前」・「輪 1 の半径（m）」 | いちばん内側の輪。名前は 20 文字まで。半径は 1〜50000 の整数（m） |
| 「輪 2 の名前（使わないときは空）」・「輪 2 の半径（m）」 | 2 つ目の輪。使わないときは名前も半径も空にする |
| 「輪 3 の名前（使わないときは空）」・「輪 3 の半径（m）」 | 3 つ目の輪。使わないときは名前も半径も空にする |
| 「メモ」 | 円の説明に入る文。200 文字まで。空でもよい |

- 半径は内側の輪から順に大きくする。同じ値は使えない。
- 半径には半角の数字だけを入れる。小数点・符号は使えない。
- 文字数は絵文字も 1 文字と数える。
- 名前・メモの前後の半角の空白は取り除かれる。全角の空白は取り除かれない。
- 行の名前には実在の兵器の名前を書かず、「サンプル 小」のような汎用の名前にすることを勧める。JTAK は名前の中身を確かめない。

### 7.2 ボタン

| ボタン | 動き |
|---|---|
| 「行を保存」 | 欄の値で、選んだ行を書き換え、表をファイルに保存する。うまくいくと「保存しました」と出る |
| 「行を足す」 | 「新しい行」というラベルで、輪が 1 つ（「内側」100 m）の行を表の最後に足し、保存する。足した行が選ばれる。表が 50 行のときは押せない |
| 「行を消す」 | 確かめの画面に「{ラベル} を消します」と出る。「実行」を押すと行を消して保存する。「やめる」を押すと何もしない。表が 1 行のときは押せない |
| 「既定の表に戻す」 | 確かめの画面に「表を既定の 3 行に戻します。いまの行は消えます」と出る。「実行」を押すと、既定の表（3.2）をファイルに保存する。「やめる」を押すと何もしない |
| 「再読み込み」 | 表のファイルを読み直す。編集の欄に入れていた値は捨てる |

- 「既定の表に戻す」はファイルを消さずに既定の表を書き込む。このため、そのあとの表の状態の行は「表: 既定（ファイルなし）」ではなく「表: ファイル（3 行）」になる。
- 保存すると、「兵器の行」の一覧も新しい表で作り直される。次に描く円から、新しい値が使われる。すでに描いた円は変わらない。
- 編集の欄の値は保存するまでファイルに入らない。保存する前にほかの行を選ぶと、欄はその行の値に入れ替わり、入れていた値は消える。RED の画面を開き直したときも同じ。

### 7.3 入力にまちがいがあるとき

「行を保存」を押して入力が決まりに合わないと、保存せずに「入力を直してください:」と理由が出る。理由は 5 件まで出し、残りは「ほか N 件」と出る。理由の例:

- 「ラベル: 1 から 40 文字にしてください」
- 「輪 2: 名前と距離の両方を入れてください」（名前と半径の片方だけを入れたとき）
- 「輪 1: 距離は 1 から 50000 までの整数（m）にしてください」
- 「輪 2: 距離は前の輪より大きくしてください」
- 「輪を 1 つ以上入れてください」（輪の欄がすべて空のとき）

理由の文では欄の名前の「半径」を「距離」と書いている。どちらも同じ欄を指す。

### 7.4 表のファイル

- 保存先は ATAK のフォルダの中の `tools/jtak/weapons.json`。
- ファイルがないあいだは、既定の表を使う。ファイルは初めて保存したときに作られる。`tools/jtak/` のフォルダがなければ、そのときに作られる。
- ファイルは JSON で、中にも訓練用サンプル値であることを書く項目（`notice` と `trainingSampleValues`）がある。`notice` は保存のたびに JTAK が決まった文で書き直す。`notice` の文は画面にも円にも出さない。画面と円に出る訓練用の文は、JTAK が決まった文で出す。
- ファイルの形は `docs/interfaces/README.md` の「2. 兵器の表」にある。ファイルを手で直すこともできるが、決まりに合わないと読み込まれない（9 章）。
- 正しくないファイルがある状態で保存すると、前のファイルを同じフォルダに `weapons.invalid-YYYYMMDD-HHmmss.json` の名前で残してから、新しい表を書く。

## 8. 円は送らない・残さない（Q9）

- JTAK は円をほかの端末やサーバーへ送らない。
- 円を送りたいときは、利用者が ATAK の円の操作で送る（設計ではそうできるようにしている。10 章）。送った円の説明にも、TRAINING の行と訓練用サンプル値の行が付いている。
- 円は端末に残さない。設計では、ATAK を立ち上げ直すと円は消える（10 章）。

## 9. 困ったとき

| こんなとき | 出る文・わけ | すること |
|---|---|---|
| 「描く」を押しても円が出ない | 「目標の点を選んでください」: 目標が「（選ばない）」のまま、または選んだ点が地図から消えた | 「点の一覧を更新」を押し、目標の点を選び直す |
| 「描く」「行を保存」を押すと「表の行がありません」と出る | 選べる行がない | 「再読み込み」を押す。直らなければ「既定の表に戻す」を押す |
| 目標の一覧に点が出ない | 画面を開いたあとに点を置いた | 「点の一覧を更新」を押す |
| 円が重なって増えた | 「描く」を押すたびに円が足される（4 章） | 「消す」を押してから描き直す |
| 表の状態の行が「表のファイルが正しくないので既定の表を使っています」になる | 表のファイルが読めないか、決まりに合わない。下に理由が 5 件まで出る（例: 「entries[1].rings[0].radiusM: 1 から 50000 までの整数にしてください」）。ファイルが大きすぎるときは「ファイルが大きすぎます（上限 … バイト）」、読めないときは「表のファイルを読めませんでした: …」と出る | 理由を見てファイルを直し、「再読み込み」を押す。または「既定の表に戻す」を押す（前のファイルは 7.4 の名前で残る） |
| 「表を保存できませんでした: …」と出る | フォルダを作れない、ファイルに書けない、などで保存できなかった。前のファイルを別の名前で残したときは「前のファイルは … の名前で残っています」と出る | 端末の空き容量と、ATAK のフォルダに書けるかを確かめる。入力した値は欄に残っているので、もう一度「行を保存」を押す |
| 「円を描けませんでした: …」と出る | ATAK の中で円を作れなかった。その回に足した円は取り除かれる。前に描いた円は残る | もう一度「描く」を押す |
| 「円を消せませんでした: …」と出る | 一部の円を取り除けなかった | もう一度「消す」を押す。JTAK を閉じたときにも取り除きを試す |
| 「点の一覧を取れませんでした: …」と出る | ATAK から地図の点の一覧を取れなかった | 「点の一覧を更新」を押す |
| 味方の点が結果に出ない | 点の種類が味方（`a-f-` で始まる）でない、または外側の輪より遠い | ATAK で点の種類を確かめる |

## 10. 実機で確かめたことと、まだのこと

確かめたこと（2026-11-09、実機。詳細設計 04 の 4 章）:

- 表から行を選んで、目標の周りに円を描けた。
- 画面と円の説明に `TRAINING USE ONLY / 訓練用` と訓練用サンプル値の文が出た。
- 「消す」で円が消え、ほかの点は残った。

まだ確かめていないこと:

- 円の中心に点が出ないか（出ても目標の一覧に入らないか）。
- 円に ATAK の送る操作があること。JTAK が円を自動で送らないこと。
- ATAK を立ち上げ直すと円が消えていること。ATAK で円を編集（色などを変える）してから立ち上げ直しても、円が消えていること。
- `tools/jtak/` がないときに保存すると、フォルダとファイルができること。ファイルを壊すと、画面に理由が出て既定の表を使うこと。
- 味方の点を円の中と外に置いたとき、結果の文が合うこと。
- 円の説明（remarks）が ATAK の円の画面に出るかどうか。
- 表のファイルが端末のどのフォルダに置かれるか（`tools/jtak/weapons.json` の前の部分）。
