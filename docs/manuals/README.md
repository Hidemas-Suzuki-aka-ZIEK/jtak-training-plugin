## 2. JP 3-09.3（2014 年版）の日本語訳

原文: Joint Publication 3-09.3, *Close Air Support*, 25 November 2014（`docs/references.md` S4）。

- **非公式の訳です。** 原文と食い違うときは原文に従います。原文の PDF はリポジトリに入れていません。
- 訳の各節に、原文の節番号と PDF のページ（印刷のページ）を付けています。
- 原文にある数値（距離・時間など）は原文のまま訳し、足したり変えたりしていません。
  **訳の中の数値を、実際の安全距離として使わないでください。** JTAK の兵器の表（F03）は訓練用サンプル値で、この訳の数値を根拠にしていません。
- 原文の RED（Risk-Estimate Distance）の節は、定義と、別の文書（JFIRE）への参照だけで、兵器ごとの距離の表は原文にありません。
- 略語は原文のまま残しています。対訳は `jp3-09-3/README.md` の対訳表にあります。

訳のファイルの一覧は `jp3-09-3/README.md` にあります。
