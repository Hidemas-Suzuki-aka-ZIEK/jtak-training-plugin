# JTAK Manuals (English)

> **TRAINING USE ONLY / 訓練用**
>
> These documents are for using JTAK in milsim and tactical training (training and play) and for learning the terms and steps of the JTAC role.
> They are not for real operations, live-fire shooting, or controlling real aircraft (`docs/usage-scope.md` chapter 1, Japanese).
>
> Weapon values in JTAK (F03) are **training sample values**, not real safety distances, risk-estimate distances, or damage radii.

- Date: 2026-11-09
- Japanese list of manuals: [`../README.md`](../README.md) (Japanese)

These manuals describe the English screen. JTAK shows the English screen when the device language is not Japanese (`docs/detailed-design/07-english-ui.md`, Japanese).
They are English versions of the Japanese manuals with the same sections.
