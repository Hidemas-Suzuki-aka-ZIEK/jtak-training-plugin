# F03: RED（危険見積距離）の表示

- 要件: R3・R5（`docs/requirements.md`）
- 関連: `docs/usage-scope.md` U1・U2・U3・U8・Q3・Q9・Q12、`docs/interfaces/README.md`「2. 兵器の表」、`docs/detailed-design/04-weapon-effects.md`

## 呼び方

画面では、この機能を **RED（危険見積距離）** と呼ぶ（2026-11-09 利用者の決定。Q12）。
用語は JP 3-09.3 の risk-estimate distance（`docs/manuals/jp3-09-3/ch3-04.md` の (10)、`docs/manuals/jp3-09-3/README.md` の用語集）による。

- モードのボタン: 「RED」
- 節の題名: 「危険見積距離（RED）（訓練用）」
- 地図のグループ名: 「JTAK 訓練用の RED」
- 輪の名前（内側・外側）は変えない。

名前を RED にしても、**値は実際の危険見積距離ではなく、訓練用サンプル値のまま**である（U2）。注意書きも変えない。
コードの識別子・ファイル名（`weapons`）と、文書の中の「兵器の表」「範囲の円」という言い方はそのまま使う。

## 目的

訓練の中で、目標の周りに「この範囲に味方がいると危ない」という目安を描き、味方の位置との関係を見る練習に使う。
**値は訓練用サンプル値で、実際の安全距離・危害半径ではない**（U2）。

## 表

- 表は JSON のファイル（形は `docs/interfaces/README.md`「2. 兵器の表」）。プラグインに既定の表を入れる。
- 使う人は **JTAK の画面の中で**表を編集する（行の名前・輪の名前と距離・メモの変更、行の追加・削除、既定の表に戻す。2026-11-08 利用者の決定「画面の中で編集する」）。編集した表は端末のファイルに保存する。
- 既定の表は汎用の区分「サンプル 小（100 / 300 m）」「サンプル 中（250 / 600 m）」「サンプル 大（500 / 1000 m）」だけにする（U3。実在の兵器の名前を入れるかは Q3。値は 2026-11-08 利用者の決定「案A」）。値は意味のない切りのよい数で、出典はない。
- 表のファイルの中にも、訓練用サンプル値であることを書く項目を持つ（読み込むときに確かめる）。
- 読み込めない表・項目の足りない表は使わず、画面に理由を出して既定の表に戻す。

## 表示

1. 目標の点（F01 で置いた点か、地図の上の点）と、表の行（区分）を選ぶ。
2. 目標を中心に、行の距離ごとに円を地図に描く（線だけ・塗りなし、内側から赤・橙・黄。2026-11-08 利用者の決定）。
3. 円の題名に「訓練用」、説明に「TRAINING USE ONLY / 訓練用」と「訓練用サンプル値 — 実際の安全距離・危害半径ではない」を入れる。
4. 地図の上の味方の点が円の中にあれば、画面に出す（判定は `core`）。
5. 円は JTAK から自動では送らず、ATAK を立ち上げ直すと消える（残さない）。使う人が ATAK の操作で円を送ることはできる（Q9。2026-11-08 利用者の決定）。

## 受入基準

- 既定の表を読み込み、目標の周りに円を描ける。画面で表を編集・保存すると、描く円が変わる。
- 表の読み込みと検証、編集の欄から行を作る処理、円の中かの判定に JUnit の試験がある。
- 円の説明と画面に、U1・U2 の文言が入っている。
- 実機で、ATAK を立ち上げ直すと円が消えていること、JTAK が円を自動で送らないことを確かめた（`docs/detailed-design/04-weapon-effects.md` 4 章）。
