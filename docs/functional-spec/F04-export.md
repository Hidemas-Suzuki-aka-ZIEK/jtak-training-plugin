# F04: 画面表示と書き出し

- 要件: R4・R5（`docs/requirements.md`）
- 関連: `docs/usage-scope.md` U1・U8、F02

## 目的

F02 で作った書式を、読み上げやすい形で画面に出し、テキストと PDF のファイルに書き出す。

## 画面表示（読み上げ用）

- ドロップダウンに、書式を 1 行 1 項目で大きめの文字で出す。項目の番号・名前・値を並べる。
- 画面の上に「TRAINING USE ONLY / 訓練用」を小さく出す（U1。下には出さない。2026-11-08 利用者の決定）。

## 書き出し

| 形式 | 中身 | 作るところ |
|---|---|---|
| テキスト（UTF-8） | 画面と同じ並び。先頭と末尾に U1 の文言 | `core` |
| PDF | 画面と同じ並び。各ページの上と下に U1 の文言 | `app`（Android の `android.graphics.pdf.PdfDocument` を使う見込み。詳細設計で決める） |

- 書き出したファイルは端末の中に置き、使う人が Android の共有の機能で渡す。
  JTAK からネットワーク・航空機（の役）に自動で送ることはしない（U8）。
- ファイルの名前に日時と書式の名前を入れる。

## 受入基準

- 書式をテキストと PDF に書き出せる。どちらにも U1 の文言が入っている。
- テキストの書き出しに JUnit の試験がある。
