# JTAK の要件

- 日付: 2026-11-08（利用者の決定をもとに作成）
- 関連: `docs/usage-scope.md`（用途の範囲・最優先）、`docs/functional-spec/`（機能ごとの仕様）

## 目的

ミルシム・タクティカルトレーニングで、JTAC（統合末端攻撃統制官）の役をする人の訓練を助ける ATAK-CIV のプラグイン。
**訓練・遊戯の用途だけ**に使う（`docs/usage-scope.md`）。

## 利用者の決定（2026-11-08）

| 項目 | 決定 |
|---|---|
| LRF の入力 | すべての方式を使えるようにする: ATAK 標準の LRF 連携、BLE で直結した LRF、手入力 |
| MVP の範囲 | 3 つの機能をすべて薄く作る |
| 兵器の加害範囲 | 編集できる汎用の表（訓練用サンプル値） |
| 出力 | 画面表示（読み上げ用）と、テキスト・PDF の書き出し |
| 対象 | ATAK-CIV 5.8.0.9、実機は利用者の Android の端末 |
| 進め方 | GitHub の private のリポジトリ |

## 機能の要件

| ID | 要件 | 機能仕様 |
|---|---|---|
| R1 | LRF で測った点を、地図の上に自動でマーキングする。ATAK 標準の LRF 連携・BLE 直結・手入力のどれからでもできる | F01 |
| R2 | ルーティング・チェックイン・ゲームプラン・CAS Brief・Restrictions・9-line を、地図の上の点と入力から作る | F02 |
| R3 | 兵器の加害範囲を、編集できる表をもとに目標の周りに描く（画面での呼び方は RED（危険見積距離）。2026-11-09 利用者の決定。値は訓練用サンプル値） | F03 |
| R4 | 書式を画面に表示し（読み上げ用）、テキストと PDF に書き出す | F04 |
| R5 | すべての出力に「TRAINING USE ONLY / 訓練用」を入れる。外す設定は作らない | 全機能 |

## 機能以外の要件

| ID | 要件 |
|---|---|
| N1 | ATAK 本体と利用者の端末を壊さない。プラグインを外せば元の ATAK に戻る |
| N2 | 通信のない場所でも使える（地図の上の点と端末の中のデータだけで動く） |
| N3 | 書式・計算・兵器の表は、ATAK なしで試験できる（ADR 0003 の `core`） |
| N4 | 兵器の表は利用者が編集できる。値は訓練用サンプル値で、実際の安全距離・危害半径ではないことを表と画面に書く |
| N5 | 書式の項目・並びは公開資料をもとにし、出典を `docs/references.md` に書く |

## 受入基準（MVP）

- ビルドの骨格: SDK を展開し、`bash software/atak-plugin/build.sh assembleDebug :core:test` が通って APK ができる。
  プラグインにツールバーのボタンと、「TRAINING USE ONLY / 訓練用」を表示する空のドロップダウンがある。
- F01〜F04: 機能仕様 F01〜F04 の「受入基準」の節。

## 範囲の外

- 実際の作戦・射撃・航空機の統制に使うこと（`docs/usage-scope.md`）。
- 航空機（の役の人）との通信の自動化・デジタルの CAS のメッセージの送受信。
- 実在の兵器の正確な諸元の収録。
